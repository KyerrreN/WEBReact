# URL: http://localhost:3001
Всего запросов: 7
## GET-запросы
- "/" - возвращает HTML страницу index.html
- "/api/freelancers" - возвращает всех фрилансеров в формате JSON, сохраненных в файле
- "/api/hired" - возвращает всех нанятых фрилансеров в формате JSON, сохраненных в файле
- "/api/format" - возвращает всех нанятых фрилансеров в форматах HTML, JSON и XML (зависит от заголовка Accept)
## POST-запросы
- "/api/freelancers" - добавляет нового фрилансера, возвращает добавленного фрилансера в виде ответа в формате JSON
- "/api/freelancers/:id" - добавляет нового фрилансера в нанятые фрилансеры, возвращает ID нанятого фрилансера в формате JSON
## DELETE-запрос
- "/api/hired/:id" - удаляет нанятого фрилансера, ничего не возвращает
